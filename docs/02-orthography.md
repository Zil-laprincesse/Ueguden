# 维古登语正字法规范

本规范规定维古登语（Ueguden）的书写系统（正字法），包括字母表、音位—字母对应、长元音、词形与音标的书写约定，以及与音系规则的接口。适用于常规体与诗歌体；诗歌体的音系调整见《诗歌体规范》。

## 一、字母表与音位对应

维古登语使用 26 个基本拉丁字母 + 8 个扩展字母（5 个扩展元音 ã æ å ø ŭ；3 个扩展辅音 ç ĉ ĝ）；另有两个钝音变体 à / ò，只用来标注重读音节，不算独立字母。音位与字母原则上对应，少数音位的历史拼写变体见第五节：

元音：a /a/、e /e/（非重读时弱化为 /ə/；音标按实际读音标注——重读位置写 /e/、非重读位置写 /ə/；长音 é 读 /eː/）、i /i/、o /o/、u /u/、æ /æ/、ø /ø/、å /ɔː/、ŭ /ʌ/、ʌ（已废弃，统一写作 ŭ）。组合元音：er /ɜ/、ér /ɜː/、oe /oə/，三者都不单独作音位。

辅音：b /b/、c /k/（不送气）、ç /s/、d /d/、f /f/、g /ɡ/、h /h/、j /d͡ʒ/、k /kʰ/（送气）、l /l/、m /m/、n /n/、p /p/、r /ʁ/（音节首）、s /s/、t /tʰ/（送气）、v /v/、w /w/、y /j/、z /z/、ĉ /tʃ/、ĝ /d͡ʒ/、bh /bʰ/、dh /dʰ/、nh /ɲ/（bh、dh、nh 仅用于借词）。送气与否由字母决定，与位置无关：c /k/ 与 k /kʰ/ 成对立。

## 二、元音 ŭ 的书写与音值

字母 ŭ 表示音位 /ʌ/（后不圆唇元音，接近英语 but 的元音）。正字法以 ŭ 书写此音位；在音标（IPA）中记为 /ʌ/。即：词形写 ŭ，音标写 /ʌ/。

示例：tŭ /tʰʌ/（说）、ŭmpre /ˈʌm.prə/（火箭）、shchŭ /ʃːʲʌ/（行动）。

历史说明：早期版本曾用 IPA 符号 ʌ 直接作字母。因 ʌ 非标准拉丁字符、字体与输入法支持差，正字法已改用 Unicode 标准字符 ŭ。ŭ 的音位值不变，仍为 /ʌ/。

## 三、长元音（尖音符）

尖音符标记长元音：á /aː/、é /eː/、í /iː/、ó /oː/、ú /uː/、ǽ /æː/。例外：er 组合读 /ɜ/，ér 读 /ɜː/（如 érla /ˈɜː.la/）；å 读 /ɔː/；oe 读 /oə/。重读音节中不出现 /ə/：e 在重读音节一律写 /e/，非重读音节写 /ə/。

双写元音亦表长音（元音相邻合并为长元音）：kár（aa→á）、stejí（ii→í）。相邻元音字母的读音规则：i / u 在另一元音前读作滑音 /j/ /w/（ia=/ja/、uo=/wo/）；a / e / o 在 i / u 前构成下降双元音（ai=/aj/、au=/aw/、ei=/ej/、ou=/ow/）；其余相邻元音按分音符号 ä ë ï ö ü 断开为两个音节（oë=/o.ə/，与 oe=/oə/ 相对）。

钝音符（à / ò）：标记该音节为词的重读音节（如 -gàlo、-gòle、lànga），不改变元音音值——à 仍读 /a/、ò 仍读 /o/。分音符号（ä ë ï ö ü）：表示相邻元音分属两个音节，如 oë /o.ə/。音标一律使用标准 IPA 重音符 ˈ，不在音标内书写 à / ò。

## 四、词形与音标的书写约定

词典中每个词条以「词形 /音标/ 词类 释义。词源：…」记录。词形使用正字法字母；音标使用 IPA 符号，二者一一对应，词形中的 ŭ 对应音标 /ʌ/、t/k 对应送气 /tʰ//kʰ/ 等。

词形规则：词干末尾不保留多余的双写辅音（bella→bela）；词根 + 词缀连接时按连接音变（见《高级语法》1.1）处理。

## 五、同音位拼写与历史遗留

因历史借词与早期设计，个别音位存在多种拼写：/d͡ʒ/ 写作 j 或 ĝ；/k/ 写作 k（送气）或 c（不送气）；/s/ 写作 s 或 ç。本规范建议：新造词优先使用 j（/d͡ʒ/）、k（/kʰ/ 送气）、s（/s/）；ĝ 与 ç 保留于既有借词（如 ĝepatroj、çaira）中，不强行改写，以维持词源可识别性。ç 与 s 同音、ĝ 与 j 同音，属历史层次，不构成新造词的区别手段。

扩展辅音 ĉ /tʃ/、ĝ /d͡ʒ/、ç /s/ 已纳入字母表；r 依位置三值（音节首 /ʁ/、音节尾 /ɹ/、辅音丛 /r/）。

## 六、大小写与专名

专有名词首字母大写（Ukraín、Kozak）。句子首字母、独立词条首字母亦大写。大写变体遵循基本字母（H、I、K、U、W 等；扩展字符一般不用于专名）。

## 七、音系—正字接口

正字法直接反映音系：送气（t/k→/tʰ//kʰ/，p→/p/；送气在词首、词中、词尾与辅音丛中保持一致，不因位置改变）、r 三值、n+软腭→/ŋ/（n 在 k、g 前）、x→/ks/。词尾浊塞音清化（-b/-d/-g → [p]/[t]/[k]）属口语实现层，词典音标保持音位转写，不标注清化结果。造词时须校验音系（用词典的 toIpa 生成音标核对），并遵循本规范的字母—音位对应。
