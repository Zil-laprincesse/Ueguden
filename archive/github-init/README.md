## 为什么会有这个目录

初次上传时，各子目录被**逐个压平上传**，并各自生成了同名分支
（`docs`、`dictionary`、`tools`、`corpus`、`archive`……），
导致仓库根目录是一堆散文件、所有嵌套路径 404。

修正方式是把完整目录树一次性推送到 `main`，并删除那些临时分支。
删除前把分支上**仅存于该处**的两份文件抽出来存进本目录，确保不丢内容。
